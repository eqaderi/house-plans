# skills/

Reusable, provider-neutral task instructions for agents (for example "run a
site verification round" or "conduct one interview round"). Each skill will
reference `docs/AGENT_CONTRACT.md` and the CLI commands it uses.

Skills are planned for implementation in **Stage S2 (Agent skills)**; see
[docs/PROJECT_TRACKER.md](../docs/PROJECT_TRACKER.md) §F Stage S2. None exist yet.
