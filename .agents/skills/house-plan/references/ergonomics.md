# Clearances and ergonomic dimensions (mm)

For furniture-first planning and, once fixtures and furniture are modelled,
for automated clearance checks (each clearance becomes a rectangle that must
lie inside the room and overlap no other clearance, wall or door swing).
**P** = read in the primary text; **S** = secondary source; **U** = not
verified. NKBA = Kitchen Planning Guidelines (kb.nkba.org, edition based on
IRC 2015); NDSS = UK Nationally Described Space Standard; HN1/HN2 =
hamyarnazer.com pages quoting Mabhas 4.

Sources disagree on: WC centreline (381 code minimum vs 457 recommended),
washbasin centreline to wall (381 vs 508), shower size, DIN 18065 maximum
riser (200 vs 190). Use the comfortable value unless the room is tight, and
say which one you used.
