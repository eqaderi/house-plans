# project-data/

Git-ignored scratch space for owner material that is **not** part of a project:
files you are still sorting, one-off conversions, or anything you do not want in
the repository. Everything in this folder except this README is ignored.

Projects live in `projects/<name>/` (ADR 0009). Your own house is
`projects/my-house/`; start another with
`.venv/bin/house-ai project new <name> --actor human:<you>` and follow the README
it writes.

Never copy anything from here into `examples/`, `tests/` or `docs/`, and never
send it to an AI provider without explicit consent (`docs/AGENT_CONTRACT.md`,
section 5).
