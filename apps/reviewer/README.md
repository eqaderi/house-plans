# apps/reviewer (Stage S4)

A minimal desktop concept reviewer app (formerly Milestone E) for site, terrain,
plans, labels, dimensions, areas, north, circulation, issues and version
comparison. It will read project data through the JSON Schemas in `/schemas` and
render SVG generated from the canonical model.

Planned for implementation in **Stage S4 (Desktop concept reviewer app)**; see
[docs/PROJECT_TRACKER.md](../../docs/PROJECT_TRACKER.md) §F Stage S4. Nothing is
implemented yet.
